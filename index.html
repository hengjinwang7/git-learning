代码的四个家

工作区Working Directory
→
暂存区Staging Area
→
本地仓库Local Repository
→
远程仓库GitHub

每一次改动从左到右「搬家」，git status 会报告它现在住在哪。

日常口诀：查 → 装 → 存 → 推

查 git status → 装 git add → 存 git commit → 推 git push

团队协作时，推送前先拉取：git pull。背下这四步，覆盖 90% 的日常场景。

常用命令速查

命令作用
git status --short --branch看现状（简洁版，含远程同步状态）
git add 文件名把改动装进暂存区
git commit -m "说明"打包成一次永久存档
git log --oneline --decorate查看提交历史（一行一提交）
git push把本地提交上云（首次需 -u origin main）
git diff逐行看改了什么
git remote -v查看远程仓库关联
git check-ignore -v 路径验证忽略规则是否命中
